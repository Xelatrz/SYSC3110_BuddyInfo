Create an address book:
curl.exe -i -X POST -H "Content-Type: application/json" -d '{}' http://localhost:8080/addressBooks

Create a buddy:
curl.exe -i -X POST -H "Content-Type: application/json" -d '{\"name\":\"Alice\",\"phoneNumber\":\"000\"}' http://localhost:8080/buddyInfoes

Add a buddy to the address book:
curl.exe -i -X PUT -H "Content-Type: text/uri-list" -d "http://localhost:8080/buddyInfoes/12" http://localhost:8080/addressBooks/3/buddyList

Display address book contents with template:
curl.exe "http://localhost:8080/addressbook?id=1"
curl.exe "http://localhost:8080/addressbook?id=2"
curl.exe "http://localhost:8080/addressbook?id=3"

Display all address books (no template):
curl.exe "http://localhost:8080/addressBooks"

Display all buddies (no template):
curl.exe "http://localhost:8080/buddyInfoes"
